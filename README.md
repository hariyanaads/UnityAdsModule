## 🚀 Instalasi

1. Install [LSPosed](https://github.com/LSPosed/LSPosed) (requires Root + Magisk)
2. Download dan install APK module ini
3. Aktifkan module di LSPosed Manager
4. Reboot device
5. Buka aplikasi untuk mengatur multiplier dan fitur
